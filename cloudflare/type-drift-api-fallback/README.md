# Cloudflare Worker: type-drift-api-fallback

`index.js` is the deployable bundled entrypoint matching the live Worker. Keep this file versioned in GitHub whenever the Worker is changed; do not rely on an untracked dashboard/API-only patch.

## Important deployment notes

- The live Worker is `type-drift-api-fallback`.
- Its runtime bindings include `ALLOWED_ORIGIN` and the secret `DATABASE_URL`. Never commit secret values.
- The entrypoint is a bundled JavaScript artifact, not the original unbundled TypeScript source. Treat it as the deployable source of truth until a maintainable upstream Worker source and build step are added.
- Changes to the main Next.js app do not automatically deploy this Worker. When changing Worker behavior, update `index.js`, deploy the same artifact to Cloudflare, and verify the deployed content and bindings.

## NPC DM invariants

- An NPC reply is stored with `sender_guest_key` set to `ai:darling` or `ai:lsi-worm`, and the human participant as recipient.
- Bottle NPC replies use `bottle-{id}-npc-pair-{sorted participant IDs}` as their thread ID.
- NPC replies generated by the bottle-engagement worker are written to both `replies` and `direct_messages`.
- The `ai_reply` API path must not persist generated NPC text as if it were authored by the human user.
